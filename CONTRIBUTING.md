# Contributing to Awesome Crypto Mining

Thank you for your interest in contributing to **Awesome Crypto Mining**! 

We welcome submissions of new tools, calculators, hardware documentation, stratum mining pools, and open-source software that help miners and Proof of Work investors make informed, data-driven decisions.

---

## Submission Guidelines

Before submitting a Pull Request, please ensure your contribution adheres to the following criteria:

1. **Relevance:** The project must be directly related to Proof of Work (PoW) cryptocurrency mining, hardware, software, pools, economics, or mathematical modeling.
2. **Quality & Activity:** Tools and software must be actively maintained and functioning. Deprecated or abandoned projects will be rejected or archived.
3. **No Scams:** No Ponzi schemes, fake cloud-mining contracts, closed-source unverified miners with malicious payloads, or scam sites.
4. **No Referral / Affiliate Links:** Links must point directly to the project's canonical website or official open-source repository. Affiliate or referral tags are strictly prohibited.
5. **One Entry Per Project:** A project gets one entry per section. It may additionally appear inside a coin subsection **only** if it provides a page, client, pool or dataset specific to that coin — a generic homepage repeated under every coin will be removed. This applies equally to explorers, pools, benchmark databases and calculators.
6. **Link Verification:** Check the link before submitting. It must resolve to the live project (not a parked domain, a redirect to an unrelated site, or a 404), and the repository or site must show activity within the last 12 months.
7. **Formatting:**
   - Follow the established list format: `- **[Project Name](https://url)** — Concise description highlighting what the tool does and why it is useful.`
   - Keep descriptions objective, informative, and grammatically sound.
   - In the flat tool sections (calculators, hardware, software, firmware, pools), insert new items in **alphabetical order**.
   - In the per-coin subsections of *PoW Coins*, order entries by **role** instead: node software → explorers → wallets → mining software → pools → data and economics. Within a role, alphabetical order applies.
   - Place a coin under the algorithm family it actually mines with.

## How to Submit a Pull Request

1. **Fork** this repository.
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/<your-username>/awesome-crypto-mining.git
   ```
3. Create a descriptive branch:
   ```bash
   git checkout -b add-my-mining-tool
   ```
4. Add your entry to `README.md` in the appropriate category.
5. Commit your changes with a clear commit message:
   ```bash
   git commit -m "Add [Project Name] to [Section]"
   ```
6. Push to your fork:
   ```bash
   git push origin add-my-mining-tool
   ```
7. Open a **Pull Request** explaining what the tool is and why it belongs on the list.
